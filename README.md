# Kedi Klavyesi Simülatörü

## Dünyanın En Ciddi ve Hiç de Ciddi Olmayan Projesi

Bu repository, insanlığın en büyük sorunlarından birini çözmek için tasarlandı: **Kediler neden klavyenin üstünde yürür ve her şeyi mahveder?**

Cevap basit. Çünkü onlar kedidir. Ve biz, bu evrensel gerçeği simüle etmek için bir yazılım geliştirdik.

### Özellikler (Abartılı Liste)

- ✨ Gerçekçi kedi yürüyüşü simülasyonu (rastgele tuşlara basar)
- 🐱 Miyav sesi çıkarmaz ama çıkarmış gibi hisseder
- 💻 Dosyalarınızı silmez, sadece silmiş gibi yapar
- ⏱️ Gerçek zamanlı gecikmelerle "kedinin düşünme süresi"
- 🌟 Hiçbir işe yaramaz ama çok eğlencelidir
- 🚫 Patates içermez (kesinlikle)

### Kurulum

```bash
python kedi_klavyesi.py
```

Hepsi bu. Başka hiçbir şeye ihtiyacınız yok. Çünkü kedi de hiçbir şeye ihtiyaç duymaz. Sadece klavyeye.

### Uyarı

Bu program, gerçek bir kedinin yerini tutmaz. Gerçek kedi daha yıkıcıdır. Bu sadece bir simülasyondur. Lütfen gerçek kedinizi klavyeden uzak tutmayın, o zaten gelir.

### Katkı

Pull request atmayın. Kediler pull request anlamaz. Sadece merge ederler. Ya da etmezler. Kimse bilmez.
